# Krish Thakkar — Portfolio

A responsive, editorial-style developer portfolio for Krish Thakkar.

## Run locally
This is a static website. Open `index.html` in a browser, or serve the folder with any static file server.

## Deploy
The repository can be deployed directly to GitHub Pages, Netlify, or Vercel as a static site. No build step is required.

## Personal assets
Place Krish's portrait at `assets/krish.jpg`. The page references this path for the hero portrait.

## Content
Project descriptions, education, internship, skills, certificates and contact details are based on the supplied resume. The illustrated project previews are editorial mockups, not captured product screenshots.
